## 6. Bugs Discovered in Production Code

### EDV-261 [High] — Review: course reviews always 403 for private/non-live courses due to missing await and wrong argument in getCourseAccess

**File:** `src/modules/review/review.service.js` → `getPaginatedReviewsByCourseId`

**Root cause (3 problems in one call):**

1. **Missing `await`** — `getCourseAccess` is an `async` function. The call at line ~94 is:
   ```js
   const { isOwner, isEnrolled } = getCourseAccess(user.role, user.userId, courseId);
   ```
   Without `await`, the destructure operates on a `Promise` object, so both `isOwner` and `isEnrolled` are `undefined`.

2. **Wrong argument** — `courseId` (a plain string) is passed instead of the already-fetched `course` document. `getCourseAccess` reads `course.instructor.ref` and `course._id`, which are not accessible on a plain string.

3. **Wrong logical operator** — Access guard is `!isOwner || !isEnrolled` (OR). For a user who is only enrolled (not owner), `!isOwner` is `true` so the OR short-circuits and throws 403. Correct is `&&` (deny only when neither owner nor enrolled).

**Impact:** Any call to `GET /api/courses/:id` for a private or non-live course returns 403 "Course is currently unavailable" to enrolled students — even though they should have access.

**Jira:** EDV-261 — filed immediately.
