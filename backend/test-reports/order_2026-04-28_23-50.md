## 6. Bugs Discovered in Production Code

### EDV-265 [High] — Order: placeOrder allows duplicate pending orders for same course due to missing uniqueness check

**File:** `src/modules/checkout/checkout.service.js` → `placeOrder`

**Root cause:** `placeOrder` validates only that the selected courses are in the cart. It does NOT check whether a pending order already exists for any of the selected courses. Additionally, cart contents are only cleared when `isFree = true` (free checkout via `bulkRemoveFromCart`) — paid orders leave the cart intact. This means:
1. Student adds COURSE_A to cart
2. Creates pending order for COURSE_A → cart not cleared (paid flow)
3. Calls `POST /api/orders` again with `[COURSE_A]` → second 201, second pending order created

This can produce unlimited duplicate pending orders for the same course per student.

**Status:** ❌ Intentional-fail test in place (test #13). Jira: EDV-265.
