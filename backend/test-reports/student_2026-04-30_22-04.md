## Bugs Discovered in Production Code

### EDV-257 [Critical] — GET /api/student/courses returns array of empty arrays due to recursive mapper call

**File:** `src/modules/enrollment/enrollment.mapper.js`

`toEnrolledCourseRowDtoList` calls itself recursively instead of calling `toEnrolledCourseRowDto` for each item. This means every course row in the response is an empty array `[]` instead of a course DTO object. Search/field assertions are collateral failures of this bug.

**Jira ticket:** EDV-257 (Closed)

---

### EDV-258 [Medium] — PATCH /api/student/profile silently ignores bio field

**File:** `src/modules/student/student.service.js` — `getUpdateData()` does not map `data.bio` to any field.
**File:** `src/modules/student/student.mapper.js` — `toStudentProfileDto` does not include `bio`.

The `bio` field passes Zod validation (it is declared in `updateProfileRequest`) but is silently dropped in `getUpdateData`. It is also absent from the DTO mapper, so even if saved it would not be returned.

**Jira ticket:** EDV-258 (In Progress)
