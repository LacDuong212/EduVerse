## 4. Bugs Discovered in Production Code

### BUG-1 — Duplicate curriculum video collection in `clearPendingChanges`

| Field | Detail |
|---|---|
| **Severity** | Medium |
| **Endpoint** | `DELETE /api/instructor/courses/:courseId/changes` |
| **File** | `backend/src/modules/course/course.service.js` |
| **Location** | Lines ~730–760 |
| **Description** | The `if (hasCurriculumChanges)` block that collects `lectureVideos` into `videosToRemove` is copy-pasted twice in the same function. This causes all pending curriculum videoIds to be pushed **twice** into `videosToRemove`. |
| **Root cause** | Copy-paste error — the same block appears two consecutive times with identical condition and body |
| **Expected** | Each videoId appears in `videosToRemove` exactly once |
| **Actual** | Each videoId appears twice |
| **Impact** | `expireOrphanVideos` is called with duplicate IDs. Functional impact depends on idempotency of that function. Possible: double-expiry API calls; silent failure on second attempt if service is not idempotent. |
| **Action** | **DO NOT FIX** in this PR — log for backend team to address separately |
