## Bugs Discovered in Production Code

### EDV-259 [Medium] — Wishlist: thumbnail image always null due to typo in mapper

**File:** `src/modules/wishlist/wishlist.mapper.js`

`toWishlistDto` reads `course?.thumnail` (missing `a`) instead of `course?.thumbnail`. The Course model field is `thumbnail`, so every wishlist item returns `thumnail: null`.

**Jira ticket:** EDV-259 (In Progress)

---

### EDV-260 [Low] — Wishlist: phantom `lectureCount` field always 0 due to wrong field name in mapper

**File:** `src/modules/wishlist/wishlist.mapper.js`

`toWishlistDto` includes both `lecturesCount: course?.lecturesCount` (correct) and `lectureCount: course?.lectureCount || 0` (wrong — the Course model has `lecturesCount`, not `lectureCount`). The `lectureCount` field is always `0` and should not be in the DTO.

**Jira ticket:** EDV-260 (In Progress)
