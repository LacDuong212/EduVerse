## 4. Bugs Discovered

### BUG-1: EDV-257 — `GET /api/student/courses` returns empty arrays instead of course objects
| Field | Value |
|-------|-------|
| **Jira** | EDV-257 |
| **Severity** | Critical |
| **File** | `backend/src/modules/enrollment/enrollment.mapper.js`, line 43 |
| **Root Cause** | `toEnrolledCourseRowDtoList` recursively calls itself instead of `toEnrolledCourseRowDto` |
| **Symptom** | `result` array contains `[]` items instead of course objects |
| **URL** | `GET /api/student/courses` |
| **Expected** | `result[0] = { courseId: "...", title: "...", percentage: 0, ... }` |
| **Actual** | `result[0] = []` (empty array — hits `if (!Array.isArray(courses)) return []` on each item) |
| **Failing Tests** | `Success: Search courses (fuzzy)`, `Success: Course row has expected fields`, `[BUG EDV-257] Each result item should be a course object` |
| **Fix (DO NOT APPLY)** | Change `toEnrolledCourseRowDtoList(course)` → `toEnrolledCourseRowDto(course)` on line 43 |

### BUG-2: EDV-258 — `PATCH /api/student/profile` silently ignores `bio` field
| Field | Value |
|-------|-------|
| **Jira** | EDV-258 |
| **Severity** | Medium |
| **Files** | `student.service.js` (getUpdateData fn + populate select), `student.mapper.js` (toStudentProfileDto) |
| **Root Cause** | `bio` present in User model and validation schema, but (1) not copied in `getUpdateData`, (2) not in `select` string for `populate`, (3) not mapped in `toStudentProfileDto` |
| **URL** | `PATCH /api/student/profile` with body `{ bio: "My bio text" }` |
| **Expected** | `200 OK`, `result.bio === "My bio text"` |
| **Actual** | `200 OK`, `result` has no `bio` field — update silently discarded |
| **Failing Tests** | `[BUG EDV-258] bio field should be saved and returned but is silently ignored` |
| **Fix (DO NOT APPLY)** | Add `bio` to `getUpdateData`, to populate `select`, and to `toStudentProfileDto` |
